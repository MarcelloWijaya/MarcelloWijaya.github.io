# Marcello's portfolio

React + Tailwind CSS + Vite. Hosted on GitHub Pages using the default `MarcelloWijaya.github.io` address.

## Local development

Use Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

Production build: `npm run build`. Output: `dist/`.

## GitHub Pages

In the GitHub repository, open **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**. Push to `main` to run `.github/workflows/pages.yml`, or run the workflow manually from Actions. No custom domain is required.

## Updating content

Edit `src/main.jsx` for biography, project links, and experience; edit `src/style.css` for the design. Public assets live in `public/assets/`.

Project artwork is an illustrative concept, not a screenshot of the original project. The existing student biography and work dates were retained and should be updated when appropriate.
